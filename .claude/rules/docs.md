# Documentação

- Seja factual e curta.
- Não duplique código ou conteúdo já evidente no repositório.
- `STATE.md` deve caber, preferencialmente, em 30-50 linhas.
- `ARCHITECTURE.md` registra estrutura durável, não diário de desenvolvimento.
- `DECISIONS.md` registra somente decisões relevantes e suas razões.
- Não transforme documentação em histórico de cada prompt.
